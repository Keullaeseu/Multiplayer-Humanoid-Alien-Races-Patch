# Multiplayer Humanoid Alien Races Patch

A RimWorld Multiplayer compatibility patch for [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762).

This mod is designed to improve multiplayer synchronization when playing with the [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762) mod and RimWorld Multiplayer.

## Features

- Adds multiplayer compatibility for [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762).
- Synchronizes styling station appearance edits (color channels, body addon variants and colors).
- Keeps the styling station live preview in sync on the multiplayer dummy pawn.

## Requirements

- RimWorld
- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- RimWorld Multiplayer
  - [GitHub version](https://github.com/rwmt/Multiplayer) or [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745) version
- [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)

The host and every connected player must use compatible versions of all required mods.

## Installation

### Steam Workshop

Subscribe to the required mods and add them to your RimWorld mod list in the following order:

1. Harmony
2. Core
3. Royalty, Ideology, Biotech, and Anomaly, if applicable
4. RimWorld Multiplayer
5. [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)
6. [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)

The patch should load after both RimWorld Multiplayer and [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762).

### Manual Installation

1. Download the latest release from the [**Releases**](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest) section.
2. Extract the mod folder into your RimWorld `Mods` directory.
3. Enable the required mods in RimWorld.
4. Use the recommended load order listed above.
5. Make sure every multiplayer player has the same mod list, configuration, and load order.

## Multiplayer Usage

All players should have the following mods installed and enabled:

- RimWorld Multiplayer
- [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)
- [Multiplayer Humanoid Alien Races Patch](https://github.com/Keullaeseu/Multiplayer-Humanoid-Alien-Races-Patch/releases/latest)
- All required Humanoid Alien Races dependencies

The host and all connected clients should use the same:

- RimWorld version
- RimWorld Multiplayer version
- Humanoid Alien Races version
- Multiplayer Humanoid Alien Races Patch version
- Mod configuration
- Mod load order

Do not add, remove, update, or reorder mods while players are connected to the same multiplayer session.

## Compatibility

This patch is intended to provide multiplayer compatibility for [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762).

It does not replace:

- [RimWorld Multiplayer](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745)
- [Humanoid Alien Races](https://steamcommunity.com/sharedfiles/filedetails/?id=839005762)

## Known Limitations

- Compatibility may be affected by future RimWorld updates.
- Compatibility may be affected by future updates to RimWorld Multiplayer or Humanoid Alien Races.
